General moving parts API
========================

Read :doc:`the system explanation </Scripting/MovingParts>` for composition, setup and worked examples. This reference lists public members declared by each package type. Base-type links identify inherited contracts; the topic's method index also includes the relevant package base methods. Unity framework methods inherited from ``MonoBehaviour``, ``Object`` or ``ScriptableObject`` are documented by Unity.

MovingPart
----------

**Runtime/Exterior/Parts/MovingPart.cs**

Owns rotation/translation requests, constraints and scheduled motion.

**Inherits / implements:** :ref:`ExteriorModule <evs-api-modules--exteriormodule>`.
